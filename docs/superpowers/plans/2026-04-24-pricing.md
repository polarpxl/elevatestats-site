# Pricing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `/pricing` route that presents Free and PRO plans with a live Monthly/Yearly billing toggle, a "Why PRO" value section, an accordion FAQ, a final CTA band, and the shared Nav + FooterCta from the homepage.

**Architecture:** Server-rendered page that imports client components only where interactivity is needed (billing toggle, FAQ accordion). Plan data lives in `src/lib/pricing.ts` as a single source of truth. Reuses all existing primitives and layout shells — no duplication of Nav/Footer/Button/Container/Placeholder.

**Tech Stack:** Next.js 16.2.4 (App Router), React 19, TypeScript, Tailwind CSS v4, Framer Motion 12. No new dependencies.

## PricingPlans component shape (the interactive bit)

Client component. Imports `pricing` from `@/lib/pricing` and `links`, plus `Button` and shared UI.

Structure:
```
<PricingPlans>
  <BillingToggle value={period} onChange={setPeriod} />   // pill switch
  <div className="grid md:grid-cols-2">
    <PlanCard plan={pricing.free} period={period} />      // price never changes
    <PlanCard plan={pricing.pro} period={period} popular />
  </div>
</PricingPlans>
```

**Billing toggle visual:**
- Two-label pill: `[Monthly] [Yearly]` with an orange thumb that slides between them
- Thumb animation via Framer Motion `layoutId` on a positioned `<motion.div>` — no manual position math needed; `layout` animates between the two label positions automatically
- Small "Save 17%" orange pill to the right of "Yearly" (non-clickable, just visual affordance)
- `role="group"` on the wrapper, each side implemented as `<button type="button" aria-pressed={...}>` for accessibility

**PlanCard:**
- Full-width on mobile, 2-up on `md`+
- White background, `rounded-card`, `ring-1 ring-black/5`, `p-6 md:p-8`. PRO gets an extra `ring-brand-orange/30` highlight plus a "Most Popular" badge in the top-right corner.
- Layout top-to-bottom: plan name (Poppins 700 text-xl) → tagline (brand-gray text-sm) → price block → feature list → CTA button pinned bottom via `mt-auto`.
- **Price block (PRO card, Monthly):** big `$14` in Poppins 800 text-5xl, `/mo` suffix in text-lg brand-gray.
- **Price block (PRO card, Yearly):** big `$140` + `/year`; secondary line beneath: `That's $12/mo billed annually. Save 17%.`
  - Monthly-equivalent: `Math.round(priceYearly / 12)` → `$12` (rounded from 11.67). Using `Math.round` for a clean integer; if you want `$11.67` exact, we can switch — flagging the choice.
- **Price block (Free card, both periods):** big `$0` with `forever` suffix.
- Feature list: unordered, each item starts with a small orange checkmark (inline SVG). No custom component — just a flex row with a `<svg>` and a `<span>`.
- PRO's CTA uses `variant="primary"`. Free's CTA uses `variant="secondary"`.

**Why single client component:** the billing toggle and PRO card price move together on state change. Keeping both inside one `'use client'` boundary avoids prop-drilling or context, and isolates client-side JS to the smallest possible subtree. Everything above (`PricingHero`) and below (`WhyPro`, `Faq` internals, `PricingFinalCta`, `FooterCta`) stays server-rendered.

## FAQ accordion shape

Client component. Structure:
```
<Faq>
  const [openIndex, setOpenIndex] = useState<number | null>(null)
  {items.map((item, i) => (
    <FaqItem
      key={i}
      item={item}
      open={openIndex === i}
      onToggle={() => setOpenIndex(openIndex === i ? null : i)}
    />
  ))}
</Faq>
```

**Decision: single-open pattern.** Mirrors how most marketing FAQs behave and keeps the visual more focused. When the user opens a new item, the previous one closes.

**FaqItem:**
- Outer: `<div>` with a bottom border (`border-b border-black/10`)
- Header: `<button type="button" aria-expanded={open} aria-controls={panelId}>` — full-width flex row with the question (Poppins 600 text-base md:text-lg) on the left and a chevron SVG on the right. Chevron rotates 180° when open via CSS transition.
- Panel: `<AnimatePresence>`-wrapped `<motion.div>` that animates `height: 'auto'` from 0 and `opacity` 0→1 over ~200ms. Framer Motion handles measuring auto height.
- Keyboard: since the header is a real `<button>`, Tab/Enter/Space work natively.

**Why Framer Motion for height, not CSS:** CSS transitions can't interpolate between `0` and `auto`. The modern `interpolate-size: allow-keywords` feature isn't everywhere yet. Framer's `animate={{ height: 'auto' }}` is reliable and we already have it installed.

**Billing toggle markup:**
```tsx
<div role="group" aria-label="Billing period" className="inline-flex rounded-full bg-white ring-1 ring-black/10 p-1 relative">
  {(['monthly', 'yearly'] as const).map((p) => (
    <button
      key={p}
      type="button"
      aria-pressed={period === p}
      onClick={() => setPeriod(p)}
      className="relative z-10 px-5 h-10 text-sm font-heading font-semibold rounded-full transition-colors"
    >
      <span className={period === p ? 'text-white' : 'text-ink'}>
        {p === 'monthly' ? 'Monthly' : 'Yearly'}
      </span>
    </button>
  ))}
  {/* sliding thumb */}
  <motion.div
    layout
    layoutId="billing-thumb"
    transition={{ type: 'spring', stiffness: 500, damping: 40 }}
    className="absolute inset-y-1 rounded-full bg-brand-orange"
    style={{
      left: period === 'monthly' ? '0.25rem' : '50%',
      right: period === 'monthly' ? '50%' : '0.25rem',
    }}
  />
</div>
```

Actually the `layoutId` approach requires the thumb to *move between two siblings*. Simpler: use two buttons and position the thumb absolutely based on `period`. The code above does that via left/right — cleaner than layoutId for a 2-state toggle. Using Framer's `transition` on left/right via `animate` prop.

**Final toggle implementation (definitive):**
```tsx
<motion.div
  aria-hidden
  className="absolute inset-y-1 w-[calc(50%-0.25rem)] rounded-full bg-brand-orange"
  animate={{ x: period === 'monthly' ? 0 : '100%' }}
  transition={{ type: 'spring', stiffness: 500, damping: 40 }}
  style={{ left: '0.25rem' }}
/>
```

Next to the toggle (not inside it): a small orange "Save 17%" pill — `span` with `bg-brand-orange/10 text-brand-orange text-xs font-semibold uppercase tracking-[0.14em] rounded-full px-2.5 py-1`.

**PriceBlock logic:**
```tsx
function PriceBlock({ plan, period }: { plan: Plan; period: BillingPeriod }) {
  const isFree = plan.priceMonthly === 0 && plan.priceYearly === 0
  if (isFree) {
    return (
      <div className="mt-6 flex items-baseline gap-2">
        <span className="font-heading text-5xl font-extrabold">$0</span>
        <span className="text-brand-gray">forever</span>
      </div>
    )
  }
  if (period === 'monthly') {
    return (
      <div className="mt-6">
        <div className="flex items-baseline gap-2">
          <span className="font-heading text-5xl font-extrabold">${plan.priceMonthly}</span>
          <span className="text-brand-gray">/mo</span>
        </div>
        <p className="mt-1 text-sm text-brand-gray">Billed monthly in {plan.currency}.</p>
      </div>
    )
  }
  const equivalent = Math.round(plan.priceYearly / 12)
  return (
    <div className="mt-6">
      <div className="flex items-baseline gap-2">
        <span className="font-heading text-5xl font-extrabold">${plan.priceYearly}</span>
        <span className="text-brand-gray">/year</span>
      </div>
      <p className="mt-1 text-sm text-brand-gray">
        That&apos;s ${equivalent}/mo billed annually. Save {'yearlySavingsPercent' in plan ? plan.yearlySavingsPercent : 0}%.
      </p>
    </div>
  )
}
```

**Decision flagged for approval:** `Math.round(140/12) = 12`. Displayed as `$12/mo`. Exact would be `$11.67`. I'll go with `$12` rounded unless you'd rather show `$11.67`.
