Lines tell Elevate who plays together. Once a game has lines, every goal asks which line and pair were on the ice, and that's what powers plus-minus. Lines are a PRO feature and they're optional: a game without lines tracks exactly as before.

<Callout type="info">Using Elevate Coach too? It's the same lineup. Set your lines in either app and they show up in both.</Callout>

## How it works

Each game has one lineup:

- **Forwards** - Line 1 to Line 3 (LW, C, RW). Tap **+ Add Line 4** if you dress a fourth line.
- **Defence** - Pair 1 to Pair 3 (LD, RD). Tap **+ Add Pair 4** if you need one.
- **Power play** - PP1 and PP2, five spots each.
- **Penalty kill** - PK1 and PK2, four spots each.

Power play and penalty kill units can use players who are already on a line. A player can only be in each unit once.

Goalies aren't part of your lines. You still pick the starting goalie on Game setup and change goalies in the tracker.

When you set up a new game, Elevate copies the lines from your last game, so most nights you just check them and swap whoever is different. Only Active players can go on a line. Anyone set to Injured or Inactive is left out of the copy, and their spot stays empty.

## Set lines before the game

1. Tap **Track**, then create or pick your game.
2. On Game setup, tap **Lines** (under Starting goalie). If your last game had lines, you'll see "Copied from" with that game's date and opponent.
3. Tap any spot to choose a player. The list shows where each player is right now, like "Here now" or "Not in lineup". Picking someone from another line moves them and leaves a gap where they were.
4. Tap **Leave empty** to clear a spot, or **Clear all** to start over.
5. Tap **Save lines**. If nothing changed, the button reads **Looks right, done**.

Only the team owner can set lines on Game setup.

## Change lines during the game

Juggling lines mid-game? In the tracker, tap the settings icon at the top right to open Live Game Settings, then tap **Edit lines**. Owners and stats keepers can both do this. A keeper's changes update the coach's lineup for that game too.

Editing lines needs a connection. Goals still record who was on the ice when you're offline, using the lines the game already has.

## A few things worth knowing

- If a stats keeper starts a game that has no lines yet, the lines start empty. Set them in **Edit lines**, or have the owner set them on Game setup before the game.
- If a player in the lineup is set to Injured or Inactive, their spot shows as empty with a short note, and they won't show up on the ice for goals.
- Lines are ignored while Quick mode is on.
- To learn how goals use your lines, see [Plus-minus and who was on the ice](/support/plus-minus-and-who-was-on-the-ice).
